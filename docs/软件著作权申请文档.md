## 二、软件功能概述

### 2.1 软件简介

RecurWords 是一款基于"递归释义树"交互范式的英文词汇学习软件。用户输入一个英文单词后，软件展示其英文释义；释义中的每个单词均可被点击，递归展开为新的释义节点，形成无限层级的知识树。软件集成了大语言模型（LLM）语义判分功能，能够智能判断用户输入的中文释义与标准释义在语义上是否等价，支持近义词匹配。同时内置错题库系统，采用加权算法对错词进行复习优先级排序，实现个性化的高效复习。

### 2.2 核心功能模块

#### 模块一：递归释义查询（核心模块）

- 用户输入英文单词，软件调用牛津词典 API 或 LLM 获取英文释义
- 释义以结构化方式展示，每个释义中的英文单词均可被点击
- 点击后递归展开该单词的释义，形成树状知识结构
- 支持无限层级展开与收起，节点状态独立管理
- 支持节点聚焦高亮、层级缩进可视化、展开动画
- 数据结构采用 WordNode 树形结构，支持父子关系、展开状态、数据来源标记

#### 模块二：LLM 语义判分

- 用户在自测模式下输入中文释义
- 软件将用户答案与牛津词典标准中文释义同时提交给 LLM
- LLM 判断两者语义是否等价，返回 JSON 结构化结果（correct/incorrect + reason）
- 支持近义词匹配（如"勤勉的"与"用功的"判为正确）
- 支持多 LLM 服务商：DeepSeek、月之暗面（Kimi/Moonshot）、零一万物、OpenAI、Ollama 本地模型
- 当 LLM 不可用时，自动降级为关键词模糊匹配（基于字符重合度）
- 判分结果记录到学习历史和错题库

#### 模块三：错题库管理

- 答错的单词自动进入错题库
- 每个错词记录：错误次数、连续答对次数、首次错误时间、最近错误时间、最近复习时间
- 采用加权排序算法计算复习优先级：
  - score = (错误次数 / 最大错误次数) × 0.5 + (距离上次错误天数 / 7) × 0.3 + (1 - 连续答对次数 / 目标次数) × 0.2
  - 得分越高，复习优先级越高
- 支持复习会话（Review Session）：按优先级依次出题，用户输入答案，实时判分
- 连续答对达到目标次数后，单词自动移入"已掌握"列表
- 支持错题库统计：总数、已掌握数、待复习数、掌握率

#### 模块四：设置与配置

- 数据源选择：牛津 API 优先 / 仅 LLM
- 牛津词典 API 配置：App ID、App Key、代理 URL
- LLM 配置：API Key、Base URL、模型名，含 6 种服务商一键预设
- 每日目标设置：连续答对次数目标（3~10 次）
- 主题切换：日间 / 夜间 / 跟随系统
- 连接测试：一键测试 LLM 和牛津 API 可用性，显示详细错误信息
- 数据管理：导出全部数据 / 清空全部数据

#### 模块五：移动端适配

- 响应式布局：适配手机和桌面浏览器
- 底部 Tab Bar 导航：查词 / 错题库 / 设置
- 触摸目标优化：所有可点击元素 ≥ 44px
- 安全区避让：适配刘海屏、底部手势条
- PWA 支持：manifest.json + Service Worker，可添加到主屏幕，支持离线访问
- Android APK 打包：通过 Capacitor 6 生成原生安装包

## 四、核心技术说明

### 4.1 递归释义树数据结构

软件核心数据结构为 WordNode 树形节点：

```typescript
interface WordNode {
  id: string;              // 节点唯一标识
  word: string;            // 英文单词
  englishDefinition: string; // 英文释义
  chineseMeanings: string[]; // 中文含义列表
  children: WordNode[];    // 子节点（递归）
  expanded: boolean;       // 是否展开
  depth: number;           // 树深度
  parentId: string | null; // 父节点 ID
  source: 'Oxford' | 'LLM'; // 数据来源
}
```

该结构支持无限层级递归展开，每个节点的状态（展开/收起）独立管理。渲染时采用递归组件 RecursivePanel + DefinitionLine，子节点动态加载，避免一次性请求过多数据。

### 4.2 LLM 语义判分算法

判分流程：
1. 用户输入中文释义（如"用功的"）
2. 系统构建 prompt，包含用户答案和牛津标准释义
3. 调用 LLM chat/completions API，要求返回 JSON 格式结果
4. 通过 Zod Schema 校验 LLM 返回的 JSON 结构
5. 校验通过则取用判分结果；校验失败则降级为关键词模糊匹配

降级匹配算法：
- 去除结构助词（的/地/得）、标点、空格
- 计算字符重合度：重合字符数 / 标准答案字符数
- 重合度 ≥ 2/3 判为正确

### 4.3 错题库加权排序算法

```
score = (wrongCount / maxWrongCount) × 0.5
      + (daysSinceLastWrong / 7) × 0.3
      + (1 - consecutiveCorrect / targetCorrect) × 0.2
```

权重设计原理：
- 50% 权重给错误频率：错得越多的词越优先复习
- 30% 权重给时间衰减：距离上次错误越久的词越需要复习
- 20% 权重给掌握度：连续答对次数越少的词越需要继续巩固

### 4.4 移动端与 PWA

- 通过 Tailwind CSS 的响应式断点（sm/md/lg）实现手机优先布局
- 安全区适配：使用 env(safe-area-inset-*) 避让刘海和底部手势条
- PWA 配置：vite-plugin-pwa 自动生成 manifest.json 和 Service Worker
- Android 打包：Capacitor 将 Web 资源包装为原生 WebView 容器，生成可安装的 APK

## 五、软件创新点

1. **递归释义树交互范式**：市面上现有词汇学习软件均采用"查词 → 固定释义列表"模式，本软件首创"释义中的每个单词均可递归展开"的交互方式，使查词过程从"查一个词"变为"展开一棵知识树"。

2. **LLM 语义判分**：传统词汇学习软件采用选择题或严格字符串匹配判分，本软件利用大语言模型理解用户输入的语义，支持近义词、语序变化、表述差异等多种情况，判分更接近人类教师。

3. **加权复习排序算法**：结合错误频率、时间衰减、掌握度三个维度计算复习优先级，相比传统艾宾浩斯曲线更灵活、更个性化。

4. **纯前端零成本部署**：无需后端服务器，所有数据存储在用户本地，开发者零服务器成本，用户零隐私泄露风险。
